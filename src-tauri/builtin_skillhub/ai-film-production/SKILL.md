# 一人成军AI制片

## 任务目标
- 本Skill用于：独立完成从创意到成片的闭环视频制作流程
- 能力包含：AI辅助分镜创作、定调筹备（风格/人物一致）、动态制作、剪辑粗剪与定剪、闭环反馈优化
- 触发条件：用户需要制作视频（短视频、广告片、剧情片、宣传片、动画等）

## 前置准备
- 资产目录结构：创建资产文件夹以管理角色、道具、场景等素材
  ```
  assets/
  ├── characters/      # 角色资产生成
  ├── props/           # 道具资产生成
  ├── scenes/          # 场景资产生成
  ├── keyframes/       # 关键画面定调
  └── storyboard/      # 分镜静帧
  ```
- 模板文件：
  - 资产目录模板：见 [assets/asset-catalog-template.md](assets/asset-catalog-template.md)
  - 分镜表模板：见 [assets/storyboard-template.md](assets/storyboard-template.md)

## 操作流程总览

本制片流程采用**双主线+闭环反馈**的工作模式，确保从创意到交付的完整可控：

### 流程架构图
```
          分镜创作主线              剪辑制作主线

         创意 → 分镜脚本 ←────────┐
                ↓                  │
            定调筹备 ←─────┘       │
         (关键分镜→连续分镜)        │
                ↓                  │
            图片增强                │
                │                  │
                └───────→ 交付 ←────┘
                           ↑
                    剪辑定剪
                      ↑
                    粗剪
                      ↑
    分镜脚本 + 动态制作 + 首尾帧 + 多图参考
```

### 三大模块说明

**模块一：分镜创作主线**
1. **创意→分镜脚本**：从创意出发，生成分镜脚本
2. **定调筹备**：以"风格一致""人物一致"为核心要求
3. **资产生成**：依次产出关键分镜→连续分镜
4. **图片增强**：优化生成结果，可循环回到分镜脚本优化

**模块二：剪辑制作主线**
1. **素材准备**：分镜脚本、动态制作、首尾帧、多图参考
2. **剪辑粗剪**：基于素材进行粗剪
3. **剪辑定剪**：参考关键分镜，完成定剪
4. **视频增强**：优化最终效果，指向交付

**模块三：闭环反馈**
交付后可触发多路径循环优化：
- 回到分镜脚本：优化分镜设计
- 回到剪辑粗剪：调整剪辑节奏
- 回到动态制作/首尾帧/多图参考：修正视频素材

### 阶段一：分镜创作主线

#### 1.1 创意出发与项目定位
- 描述背景：影片类型、目标受众、时长要求
- 明确创意核心：核心传达信息、情感目标、商业目标
- 提供必要信息：品牌调性、风格偏好、技术限制

#### 1.2 细致脚本创作
- 智能体根据创意创作**细节细致和连贯**的完整脚本
- **脚本要求**：
  - 内容连贯：情节发展自然流畅，逻辑清晰
  - 细节丰富：详细描述角色、场景、情绪、节奏
  - 对白自然：角色对白符合人物性格和情境
  - 节奏控制：明确每场戏的节奏快慢
  - 情绪标注：标注每场戏的情绪基调
- 输出完整的脚本文档，供分镜拆分使用

#### 1.3 分镜脚本生成（单镜头≤5秒）
- 根据细致脚本拆分为镜头序列
- **单镜头时长限制**：
  - 默认每个镜头时长不超过5秒
  - 除非用户有额外要求，否则严格遵循此限制
  - 短镜头可增加节奏感和吸引力
- **分镜表设计**：
  - 镜号、时长（≤5秒）、景别、运镜方式
  - **细致画面描述**：主体、动作、表情、场景、氛围
  - 角色台词
  - 资产配置（使用哪些角色、道具、场景）
  - **首尾帧描述**：描述镜头的起始和结束状态
- **输出完整分镜表**：供后续定调筹备和剪辑使用
- **循环机制**：可随时根据交付反馈回到此步优化分镜

#### 1.4 数字资产优先复用检查
- **资产复用原则**：优先复用已有的数字资产，而非重新生成
- **资产库检查**：
  - 检查角色库：是否有符合要求的人物资产
  - 检查场景库：是否有符合要求的环境资产
  - 检查道具库：是否有符合要求的道具资产
  - 检查参考图库：是否有可用的参考图片
- **复用评估**：
  - 可直接复用：直接引用现有资产
  - 需微调：基于现有资产进行微调
  - 需新生成：标注为新生成资产
- **资产配置更新**：更新资产清单，标注复用/微调/新生成状态

#### 1.5 参考生图高优先级
- **提高参考生图权重**：在定调筹备阶段，参考生图权重高于新生成
- **参考生图优先级策略**：
  1. **优先使用用户提供的参考图**
  2. **优先使用资产库中的参考图**
  3. **优先使用关键分镜作为后续分镜的参考**
  4. **新生成作为最后选择**
- **参考图管理**：
  - 建立参考图索引库
  - 按风格、人物、场景、景别等维度分类
  - 标注参考图的适用场景和优先级

### 阶段二：定调筹备

#### 2.1 核心要求：风格一致与人物一致
- **风格一致性**：
  - 确定统一的质感、光影、色彩风格
  - 为整个项目设定风格关键词组合
  - 所有资产生成必须遵循统一风格
- **人物一致性**：
  - 建立完整的人物档案
  - 生成多角度人物参考图（正面、侧面、背面、3/4侧、表情变化）
  - 保持服饰和妆造的简洁统一
- **参考图复用**：
  - 优先使用资产库中的参考图
  - 新生成的参考图要符合已有风格
  - 保持参考图的一致性

#### 2.2 资产配置与管理（优先复用）
参考 [assets/asset-catalog-template.md](assets/asset-catalog-template.md) 配置资产：
- **数字资产优先复用**：
  - 检查资产库，优先复用现有资产
  - 直接复用：无需修改，直接使用
  - 微调复用：基于现有资产进行小幅调整
  - 新生成：仅在没有合适资产时才生成
- **角色资产**：详细描述角色特征、服饰、配饰、性格，标注复用/微调/新生成
- **场景资产**：描述场景环境、光影、空间布局、天气时间，标注复用/微调/新生成
- **道具资产**：描述道具外观、细节、使用方式、与角色比例，标注复用/微调/新生成
- **提示词配置**：
  - 为需要新生成的资产配置详细的生图提示词
  - 为需要微调的资产配置修改提示词
  - **多阶段沿用提示词**：设计可跨阶段复用的提示词模板
  - 提示词要考虑后续阶段的复用需求

#### 2.3 关键分镜生成
- **识别关键镜头**：开场、高潮、结尾等情绪核心画面
- **参考生图高优先级**：
  - 优先使用用户提供的参考图
  - 优先使用资产库中的参考图
  - 新生成关键分镜时，要参考已有风格和一致性
- **生成关键画面**：
  - 详细描述画面内容、构图、光影、色彩
  - 明确风格基调：写实、卡通、电影感等
  - 产出关键分镜静帧
- **首尾帧提示词**：为每个关键分镜生成首尾帧的生图提示词
- **作用**：为连续分镜生成和剪辑定剪提供风格参考

#### 2.4 连续分镜生成（首尾帧提示词）
参考 [assets/storyboard-template.md](assets/storyboard-template.md) 生成分镜：
- **按分镜表逐镜生成**：确保画面与分镜描述完全匹配
- **内容匹配**：画面内容、景别、构图、运镜方向保持一致
- **参考关键分镜**：保持与关键分镜的风格一致性
- **数字资产优先复用**：
  - 优先使用资产库中的角色、场景、道具资产
  - 优先使用已有参考图作为参考
  - 新生成作为最后选择
- **首尾帧提示词要求**（每个分镜必选）：
  - **首帧提示词**：描述镜头起始状态的详细生图提示词
  - **尾帧提示词**：描述镜头结束状态的详细生图提示词
  - **提示词沿用**：相邻分镜的首尾帧提示词要连贯，多阶段沿用
  - **提示词模板化**：设计可复用的提示词模板，减少重复描述
- **输出连续分镜静帧**：供动态制作和剪辑使用
- **首尾帧标注**：在分镜表中标注每个镜头的首尾帧提示词

#### 2.5 图片增强与循环反馈
参考 [references/prompt-techniques.md](references/prompt-techniques.md) 和 [references/consistency-generation.md](references/consistency-generation.md)：
- **图像编辑**：AI改图、多角度生成、局部重绘、图生图
- **优化提示词**：
  - 减法确定关键要素、加法增加细节、语言准确、转换角度
  - **多阶段沿用提示词**：优化提示词时考虑后续阶段的复用
- **质量控制**：检查风格、人物、场景的一致性
- **循环反馈**：图片增强后若发现问题，可回到分镜脚本进行优化

### 阶段三：剪辑制作主线

#### 3.1 动态制作（优先使用Seedance 2.0）
参考 [references/video-generation.md](references/video-generation.md)：
- **图生视频基础**：主体+运动+场景+镜头语言
- **图镜匹配**：镜头内容与图片内容匹配、景别匹配、动势匹配（首帧动态）
- **提示词提升**：明确动作主体、注意运动时长、限制场景延展、动作拆分排序
- **导演思维**：分镜内容+场面调度+镜头语言，谁在什么地方做什么
- **数字资产优先复用**：
  - 优先使用已生成的分镜静帧
  - 优先使用已生成的首尾帧
  - 优先复用已生成的视频片段
- **视频片段生成**：按分镜表逐个生成视频片段（优先使用Seedance 2.0），输出完整视频片段序列

#### 3.2 首尾帧与多图参考
- **首尾帧控制**：精确控制视频的起始和结束状态
- **优先使用分镜中的首尾帧提示词**：
  - 根据分镜表中已标注的首尾帧提示词生成视频
  - 首尾帧提示词多阶段沿用，确保一致性
- **多图参考**：融合多张参考图的特征生成长片段
- **连续运镜**：连续的运镜生成长片段
- **进阶技巧**：相似转接、意识流、特效转接、技能释放
- **为剪辑提供更多素材选项**

#### 3.3 剪辑粗剪
- **素材整合**：将分镜脚本、动态制作、首尾帧、多图参考的素材整合
- **数字资产优先复用**：优先复用已有的视频片段和素材
- **初步剪辑**：按照分镜表进行粗剪（每个镜头≤5秒）
- **画面组接**：应用景别组接（渐进式/渐远式/跳跃式）、运镜组接技巧
- **声音设计**：初步添加对白、旁白、音乐、音效
- **输出粗剪版本**

#### 3.4 剪辑定剪
参考 [references/editing-formulas.md](references/editing-formulas.md)：
- **参考关键分镜**：以关键分镜为风格和构图参考
- **精细化剪辑**：优化画面转场、调整节奏
- **应用剪辑公式**：根据场景选择合适的剪辑公式（11种公式）
- **完善声音设计**：独白、对白、旁白、音乐、音效的完美配合
- **输出定剪版本**

#### 3.5 视频增强
- **画质提升**：优化视频清晰度和色彩
- **特效添加**：根据需要添加特效
- **调色优化**：统一色调，增强氛围
- **最终校对**：检查声音和画面的同步性
- **指向交付**

### 阶段四：闭环反馈与交付

#### 4.1 交付评估
- **质量检查**：画面、声音、节奏、情绪的整体评估
- **目标达成**：对照项目定位，确认是否达到预期效果
- **用户反馈**：收集用户或客户的反馈意见

#### 4.2 多路径循环反馈
根据交付评估结果，触发不同的循环路径：

**路径一：回到分镜脚本**
- 适用场景：分镜设计不合理、叙事问题、节奏问题
- 操作：优化分镜表，调整镜头顺序、景别、运镜

**路径二：回到剪辑粗剪**
- 适用场景：剪辑节奏不合适、画面转接不流畅、声音配乐不理想
- 操作：重新粗剪，调整剪辑节奏、转场、声音设计

**路径三：回到动态制作**
- 适用场景：视频片段质量不佳、运动效果不理想、运镜问题
- 操作：重新生成视频片段，优化提示词、调整运动描述

**路径四：回到定调筹备**
- 适用场景：风格/人物不一致、资产生成质量问题
- 操作：重新定调，优化资产配置，重新生成资产

**路径五：回到图片增强**
- 适用场景：分镜静帧质量问题、细节不足
- 操作：重新进行图像编辑和优化

**路径六：回到首尾帧/多图参考**
- 适用场景：起止状态不理想、转场不自然、素材多样性不足
- 操作：重新设置首尾帧，优化转接效果，生成新参考图

#### 4.3 最终交付
- **成片输出**：导出最终视频文件
- **素材归档**：整理和保存所有生成素材
- **项目总结**：总结制作过程中的经验教训
- **交付确认**：确认交付给用户或客户

## 注意事项
- **闭环思维**：整个流程是闭环的，交付后要积极评估反馈，及时触发循环优化
- **风格一致性**：在定调筹备阶段确立风格，整个制作过程严格遵循
- **人物一致性**：建立完整人物档案和多角度参考，确保人物一致性
- **分镜质量**：分镜脚本是基础，务必认真设计和持续优化
- **单镜头时长限制**：默认每个镜头时长不超过5秒，除非用户有额外要求
- **数字资产优先复用**：优先复用已有数字资产，避免重复生成，提高效率
- **参考生图高优先级**：提高参考生图权重，用户参考图>资产库参考图>新生成
- **提示词多阶段沿用**：设计可跨阶段复用的提示词模板，每个分镜生成首尾帧提示词
- **素材质量**：动态制作、首尾帧、多图参考要提供高质量素材供剪辑使用
- **剪辑节奏**：剪辑是最后一环，要充分运用剪辑公式，确保节奏和情绪
- **循环反馈**：不要畏惧反馈，闭环反馈是提升质量的必经之路

## 使用示例

### 示例1：短视频制作
- 功能说明：制作30秒品牌宣传短视频
- 执行方式：智能体全流程指导，按双主线执行，交付后根据反馈循环优化
- 关键参数：
  - 影片类型：品牌宣传
  - 时长：30秒
  - 风格：现代简约
  - 目标受众：年轻消费者

### 示例2：动画制作
- 功能说明：制作3分钟动画短片
- 执行方式：分阶段执行，注重动画特有的一致性和流畅度，闭环反馈优化
- 关键参数：
  - 影片类型：动画短片
  - 时长：3分钟
  - 风格：卡通风格
  - 核心情感：温馨治愈

### 示例3：剧情片制作
- 功能说明：制作5分钟剧情短片
- 执行方式：注重叙事和情感表达，多轮循环反馈优化
- 关键参数：
  - 影片类型：剧情片
  - 时长：5分钟
  - 风格：电影感
  - 核心情感：悬疑紧张
